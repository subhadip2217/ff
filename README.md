# 🔥 SURVIVAL FIRE — 2D Battle Royale Shooter

A fast-paced top-down battle royale shooter inspired by FreeFire, built with pure HTML5 Canvas and JavaScript. No frameworks, no dependencies — just open and play!

## 🎮 How to Play

Open `index.html` in any modern browser and start fighting!

### Controls

| Action | Key |
|--------|-----|
| Move   | `W A S D` or Arrow Keys |
| Aim    | Mouse |
| Shoot  | Left Click / Spacebar |
| Sprint | Shift (hold while moving) |

### Objective

Be the **last one standing** among 10 players. A **safe zone** shrinks over time — stay inside it or take damage. Pick up **loot boxes** (green crates) to restore health and upgrade your weapon.

## ✨ Features

- **10-player battle royale** — you vs. 9 AI bots
- **Shrinking safe zone** — classic battle royale mechanic
- **Bot AI** — enemies chase, retreat, and shoot at you
- **Loot system** — green crates give health + damage + fire rate boosts
- **Particle effects** — muzzle flashes, blood, death explosions
- **Real-time HUD** — health bar, kill counter, alive counter, zone timer
- **Win/Lose screen** — tracks your kills and survival time

## 🚀 Pushing to Your GitHub Repo

```bash
# 1. Clone your repo
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME

# 2. Copy the game files into the repo
cp -r /path/to/battle-royale-game/* .

# 3. Stage and commit
git add .
git commit -m "Add Survival Fire - 2D Battle Royale game"

# 4. Push
git push origin main
```
Or you can upload the files directly via the GitHub web interface (Add file → Upload files).

### Play on GitHub Pages
1. Push the files to your repo
2. Go to **Settings → Pages**
3. Source: **Deploy from a branch**, select `main` branch and `/ (rooti`
4. Save — your game will be live at `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`
